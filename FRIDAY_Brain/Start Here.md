# FRIDAY's Brain

This directory is FRIDAY's local, Obsidian-compatible long-term memory vault.

FRIDAY creates and updates notes under:

- `People/` — identity and relationship notes
- `Preferences.md`
- `Wishes.md`
- `Notes.md`

The repository intentionally contains only this onboarding file. **Do not commit personal memory notes, SQLite databases, FAISS indexes, OAuth tokens, or other runtime state.** These are generated locally and are covered by `.gitignore`.

You can optionally open this folder as an Obsidian vault.
